# 霄徵（pxc-framework-boot4）

`霄徵`是`pxc-framework-boot4`中文名字，寓意摘星踏月问天途，喻求索之道。

`pxc-framework-boot4`是一个复合型框架和工具包，由多个子模块组成，用于快速开发，是基于`Spring Boot` 4.X 的最新版本。

## 🏷️ 版本号说明

`release` 版本号格式为 `x.x.x`， 基本上保持跟 `Spring boot` 大版本一致。

例如 `4.0.0` 版本号， `4` 为 `Spring boot` `4.X` 大版本。

`snapshots` 版本号格式为 `x.x.x-SNAPSHOT`。
